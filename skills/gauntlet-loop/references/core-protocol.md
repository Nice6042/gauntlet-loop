# Core protocol

1. Explicit owner activation.
2. Specification intake and frozen quality/resource/model policy.
3. Capability discovery.
4. Dependency-safe task graph with ownership and interface contracts.
5. Parallel ready Loop Tasks when genuinely disjoint.
6. Builder implements, tests, and produces evidence.
7. Independent Critic performs complete adversarial review.
8. Builder verifies every finding and repairs verified gaps.
9. Critic re-audits the complete result until the configured verdict is met.
10. Fresh blind closure critic where required.
11. Combiner integrates a completed wave and tests system behavior.
12. Integration Critic audits the combined system; loop until closure.
13. Main Agent globally reviews against the original specification and launches later waves as needed.
14. Fresh final system audit.
15. Honest delivery with evidence, limitations, artifact identity, and resumable state.

Never weaken the frozen completion contract, silently expand permissions, or turn resource exhaustion into a pass.
